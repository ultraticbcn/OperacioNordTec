***Comandes apreses avui***
```
git init < Converteix la carpeta actual en repositori
git push < Puja els canvis al github.
git status < Indica qualsevol error que pugui tenir el git
git branch < Per veure la branca o inclús fer canvis
git commit < Per preparar la publicació dels canvis amb la possibilitat de posar un comentari 
git add
git config
git remote
```
#### Com pujar els canvis a github
Si no ho has fet mai, t'has de connectar al repositori, fent git remote add origin [adreça repositori]
Després sempre s'haurien d'haver fet canvis amb add, fet el commit amb el comentari si en vols i finalment fem push dels canvis que conté el commit.
